# What is it?
This is a repository documenting the efforts in creating a youtube video found here: https://youtu.be/2uirKSmwYAk

The goal was to figure out how to make educational youtube videos using somewhat more formal methods.

# What is in it
## ./1_needs_analysis
Markdown files documenting the process from 1_... to 6_... involving needs analysis defined in `Streamlined ID`.
scratch.md is a place where I put my thoughts throughout the project.
## ./2_script
Script and storyboard stuff along with audacity project file
## ./2.5_motion_design
Lots of styleframes to use, and then the assets exported from said styleframes to go into Blender.
It's messy, but might be useful for someone fumbling around.
## ./3_animation
.wav is exports of audacity.
.blend is the blender file I used for animation and whatnot
    A lot of things could've been done better (most recent to mind)
SceneRenders/ is where I rendered the animation in each scene.
manim_attempt/ Initial experimenting; created the thumbnail that I am going to try and use.
## ./4_editing
Editing project where I trimmed some stuff and exported it for youtube

# What tech is used?
In no particular order
    Audacity 3.7.3
        Filters and audio editing
    KDenLive 25.08.3
        Editing rendered scenes and audio together
    Blender 5.0.1
        Creation of rendered animations
    Inkscape 1.4.2
        Creation of styleframes and assets to be used in Blender
    VSCode 1.115.0
        General editing of files; began transition to emacs during project.

# What is the purpose?
The goal is to help people that are at where I was. I'm going to retain copyright to prevent low effort copycatting, but feel free to make any insights your own.

# What now?
Try to apply the method shown in the video, and if you have trouble you could try to reference this repository. It isn't the neatest thing, but it might help you when there's nothing else.
